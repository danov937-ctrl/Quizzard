# Quizzard — куиз игра с карта на България за 1–4 клас (прототип)

Мултиплейър игра в браузъра по модела на Triviador/Conquistador: 2–4 ученици завладяват
28-те области на България, като отговарят на въпроси по всички предмети от 1 до 4 клас.

## Как да я пуснеш

```bash
cd server
npm install          # само веднъж (единствената зависимост е ws)
npm start            # http://localhost:3000
GAME_SPEED=0.4 npm start   # по-кратки таймери за демонстрация
npm test             # 40 бързи игри само с ботове
```

Отвори адреса на няколко устройства в една мрежа (или с ботове на едно устройство):
„Нова игра“ → кажи 4-цифрения код → другите натискат „Влез“ → домакинът избира клас и натиска „Започни“.

## Правила (дизайн на играта)

1. **Столици.** Всеки играч получава столица (🏰, 3 кули ♥), разпределени възможно най-далеч една от друга.
2. **Завземане.** Всички отговарят на въпрос с 4 отговора (20 сек).
   - Само един е отговорил вярно → избира 2 свободни области.
   - Вярно са отговорили няколко (или всички) → **втори, числов въпрос**; най-близкият отговор
     (при равенство — по-бързият) избира 2 области, останалите верни — по 1.
   - Грешен отговор → нищо. Областта трябва да граничи с твоя територия, ако има такава свободна.
3. **Битка** (2–5 рунда, по избор на домакина). Всеки играч по ред напада съседна чужда област.
   Нападателят и защитникът отговарят на въпрос; само един верен → той печели; и двамата верни →
   числов въпрос, печели най-близкият; и двамата грешни → защитникът удържа.
   - Превзета област минава при нападателя и поскъпва с 100 т.; удържана поскъпва с 100 т.
   - Столица губи по една кула при загуба; при 0 кули нападателят взема **всички** области на играча.
4. **Край.** След последния рунд (или когато остане един играч) печели този с най-много точки
   (столица 500 т., област 200 т. + поскъпванията).

## Въпроси

- `data/questions_mc.txt` — 262 въпроса с избор (формат `клас|предмет|въпрос|ВЕРЕН|грешен|грешен|грешен`).
- `data/questions_num.txt` — 34 числови въпроса за равенства (`клас|предмет|въпрос|отговор`).
- Генерирани задачи по математика според класа (събиране/изваждане, таблица за умножение, деление, лице).
- Предмети: БЕЛ, Математика, Околен свят, Човекът и природата, Човекът и обществото, Английски,
  Музика, Изобразително изкуство, Технологии, Физическо възпитание, Компютърно моделиране.
- Играта взима въпроси за избрания клас и класа под него, без повторение в една игра.

## Техническа схема

| Част | Какво е |
|---|---|
| `server/server.js` | Node.js: статични файлове + WebSocket (`ws`), стаи с 4-цифрен код, до 4 играчи, ботове, повторно свързване след презареждане |
| `server/game.js` | Цялата логика на играта, сървърът е авторитетен (верните отговори не стигат до браузъра преди разкриване) |
| `server/questions.js` | Зареждане на въпросите и генератор на задачи |
| `public/` | Клиент без рамки: HTML/CSS/JS, SVG карта, екранна цифрова клавиатура за таблети/телефони |
| `data/map.json` | 28 области (SVG пътища, центрове, съседства), генерира се с `tools/build_map.py` |

Картата е от `provinces.geojson` в github.com/yurukov/Bulgaria-geocoding (в хранилището няма
изричен лиценз — преди пускане да се провери или да се смени с източник с отворен лиценз).

## План до пускане (≈4 седмици)

1. **Седмица 1** — тест с деца/учители на прототипа, настройка на таймерите и правилата; хранилище в GitHub.
2. **Седмица 2** — разширяване на банката до ~1500 въпроса (генериране с ИИ + проверка от учител),
   по ~50+ на предмет и клас; инструмент за преглед/редакция на въпросите.
3. **Седмица 3** — звуци и анимации, профили/прякори без лични данни, стаи за цял клас (учител като домакин), статистика.
4. **Седмица 4** — хостинг (един Node процес стига за стотици стаи), домейн, HTTPS, бета с училище, пускане.

## Сигнали за проблеми

Бутонът „🚩 Докладвай“ (горе в играта, под всеки въпрос и на началния екран) предлага готови причини
и „Друго“ със задължително поле за описание. Сигналите се записват в `data/reports.jsonl`
и се виждат на `/admin/reports?key=<ADMIN_KEY>` (само ако на сървъра е зададена променлива `ADMIN_KEY`).
На безплатния хостинг файлът се губи при рестарт, затова преди пускането сигналите ще отидат в база данни.
